# Weather release — 2026-10-09

Approved by the user after local preview, including publication to GitHub and weather.ezclickgo.com.

Includes the approved compact desktop/mobile layout and logo, voice waveform panel and direct voice flow, weather/rain presentation updates, route search and timing fixes, editable intermediate waypoints, and Undo adjacent to Navigate. The route gateway accepts up to five intermediate points; the v14 voice contract can add/replace/remove them while preserving current A/B and departure. Existing clients remain supported. Undo reverses up to 20 geometry edits in the current page session, including Clear, and cancels obsolete route responses.

Clouds use the recorded October 9 GOES series shown in the local preview, with timestamp and "recorded" label. This is not a live feed or a forecast. The new private satellite cache makes the public cloud layer independent of the developer workstation. Forecast cards still use their existing weather source.
