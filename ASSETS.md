## Find Load equipment selector
Seven original trailer images in `public/media/trailers/` extracted from the user-supplied `EZCLICK_v210_QUICK_SETUP_CARDS.html`. The 63 illustrative loads in `app/find-load-data.json` combine that prototype’s examples (including extended equipment data) with additional DEMO-prefixed examples. Each equipment group ranks three suggestions using 35% normalized gross rate, 45% normalized all-mile RPM, and 20% inverse deadhead share; six further loads can be sorted by rate, estimated trip net, or RPM. Find Load now uses a geographic mini-map with north up; all endpoints are projected from city coordinates. Road previews use bundled OSRM driving route geometry based on OpenStreetMap data, simplified to about 100 m for the mini-map. They are not truck-specific navigation. Estimates explicitly state their demo cost assumptions.

## Find Load geographic data
City coordinate source: https://github.com/kelvins/US-Cities-Database (csv/us_cities.csv). State polygon source: https://github.com/PublicaMundi/MappingAPI (data/geojson/us-states.json). Only the 36 referenced cities and contiguous state polygons are bundled in app/load-geography.json. Coordinates and polygons use the same Mercator projection. Pickup is always A and delivery B; Lexington KY is northwest of Charlotte NC. Demo mileage is retained from sample loads. Road preview geometry is stored separately in app/load-road-routes.json; user-facing attribution links to OpenStreetMap copyright. Routes sourced from https://router.project-osrm.org/route/v1/driving/ with full GeoJSON overview, 2026-09-29. No runtime calls or API keys are required.
