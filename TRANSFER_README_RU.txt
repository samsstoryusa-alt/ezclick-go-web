EZCLICK GO — исходники сайта, версия Sites 58
Исходный commit: 383076f597429dce04e38447ef9c39acac1da674

Это исходный проект, а не готовая статическая сборка для GitHub Pages.
Содержит интерфейс, изображения, последовательности кадров и серверный обработчик заявок.
Для GitHub Pages требуется отдельная статическая сборка с путём /ezclick-go-web/ и отдельный сервер для /api/inquiries.
Данные существующей базы заявок и секреты в архив не входят.
Настройки действующего Sites-хостинга не включены.
Загрузка архива в репозиторий сама по себе сайт не запускает.
При загрузке через Git рекомендуется сначала распаковать архив и проверить изменения.
